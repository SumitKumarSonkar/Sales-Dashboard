Superstore Sales Data Analysis Dashboard
📊 Project Overview
This project presents a comprehensive Data Analysis Dashboard created to visualize and gain actionable insights from the Superstore sales dataset. The project demonstrates the full end-to-end data analysis process, from data cleaning and modeling to building interactive reports.

🛠 The Data Analysis Process
The analysis followed these key stages:   

Data Collection: Importing raw sales data.   

Data Cleaning: Transforming and refining the dataset for accurate analysis.   

Data Modeling: Creating robust relationships within the data.   

Data Visualization: Building interactive reports and dashboards.   

Data Analysis: Identifying patterns, trends, and key performance indicators.   

Sharing: Communicating insights effectively.   

📈 Key Insights
Based on the dashboard analysis, here are the core findings:   

Total Records: 3,999 rows and 24 columns.   

Sales Performance: The business achieved 929K in total sales with an average profit of 26.76.   

Top Categories: Technology leads sales with 38.09%, followed closely by Furniture (33.15%) and Office Supplies (28.76%).   

Regional Dominance: The West and East regions contribute to over 90% of total sales.   

Ship Mode: Customers strongly prefer Standard Class, accounting for 60.05% of all shipments.   

Growth Trend: 2014 showed consistent growth, outperforming 2013, with September and November identified as peak months for both sales and profit.   

Top Cities: New York City and Los Angeles are the top-performing cities by quantity.
